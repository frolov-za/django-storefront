Установка самоподписного SSL-сертификата на Windows

Шаг 1: Загрузка сертификата на устройство

Загрузите файл сертификата на устройство, сохраните в загрузки.

Шаг 2: Открытие "Управления сертификатами"

Нажмите Win + R, введите mmc и нажмите Enter.

В консоли выберите Файл → Добавить или удалить оснастку (Add/Remove Snap-in).

Добавьте Сертификаты (Certificates) для Компьютера (Computer account).

Шаг 3: Установка сертификата

В дереве оснастки перейдите в Сертификаты (локальный компьютер) → Доверенные корневые центры сертификации → Сертификаты.

Кликните правой кнопкой мыши → Все задачи → Импорт.

Выберите файл .pem и завершите мастер импорта.

Шаг 4: Перезапуск браузеров и приложений

После установки сертификата перезапустите браузеры и другие приложения, чтобы изменения вступили в силу.

Примечание

Если вы используете браузер Firefox, его хранилище сертификатов отдельное — установите сертификат вручную через Настройки → Приватность и безопасность → Сертификаты.
