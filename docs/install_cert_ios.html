Установка самоподписного SSL-сертификата на iOS

Шаг 1: Загрузка сертификата на устройство

Загрузите файл сертификата на устройство, сохраните в загрузки.

Шаг 2: Установка профиля

Откройте приложение "Файлы", выберите недавние и найдите загруженный файл сертификата

Откройте файл сертификата на iPhone/iPad — система предложит установить профиль.

Нажмите Разрешить, а затем перейдите в Настройки → Основные → Профиль (или Профили и управление устройством).

Нажмите на имя сертификата и выберите Установить. Подтвердите установку, если потребуется ввести код-пароль.

Шаг 3: Доверие сертификату

После установки профиля перейдите в Настройки → Основные → О сертификате или Настройки → Основные → Информация → Настройки доверия сертификатам.

Включите переключатель Доверять для вашего сертификата.

Шаг 4: Проверка

Откройте Safari или нужное приложение и проверьте доступ к ресурсу через HTTPS. Предупреждений о недоверенном сертификате быть не должно.

Примечания

  • iOS может кэшировать настройки. Иногда требуется перезагрузка устройства.
  • Для HTTPS-соединений через Wi-Fi убедитесь, что прокси/фильтры (если есть) также доверяют сертификату.
